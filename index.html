Tech Validation

A personal, single-user set of desktop tools.

Tech Validation is a private collection of tools that its owner runs on a single personal computer to organize work notes, voice memos and documents. It is not offered to the public and has no other users.

Some of these tools connect to the owner's own Google account, with the owner's consent, to read files from Google Drive and to append notes to Google Docs that the owner chooses. What that means for data is described in the privacy policy.

Contact: use the support email shown on this app's Google sign-in screen.
